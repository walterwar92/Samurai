# MATLAB — синтез регулятора движения SAMURAI

Offline-синтез регуляторов САУ для гусеничного робота. Парадигма
**«модели → анализ → синтез»** учебника
*Козлов В.Н., Куприянов В.Е., Шашихин В.Н. «Теория автоматического
управления»*, СПбГПУ, 2008.

Код полностью соответствует разделам учебника:
- **§1.1, 1.5** — линеаризация, дискретизация
- **§3.1**     — модальный регулятор (Фробениус, pole placement)
- **§3.3**     — оптимальный регулятор (ЛКР через DARE)
- **§3.4**     — наблюдатель Луенбергера, принцип разделения

И добавляет MPC (Model Predictive Control), который в учебнике не
покрывается, но строится на тех же основаниях (DARE + lifting + QP).

---

## Запуск

В MATLAB:

```matlab
cd matlab
main
```

`main.m` последовательно вызывает все скрипты, рисует переходные
процессы и **записывает результат в `../config.yaml`** в раздел
`control:`. После этого робот при следующем старте использует свежие
матрицы — перекомпиляции Python-кода НЕ требуется.

## Файлы и что они делают

| Файл                       | Назначение |
|----------------------------|------------|
| `samurai_params.m`         | Все физические параметры робота и веса критерия. **Главная точка настройки** — все эксперименты начинаются здесь. |
| `linearize_samurai.m`      | Линеаризация нелинейной ОДУ робота. Считает якобианы df/dx, df/du в опорной точке (xbar, ubar). |
| `discretize_samurai.m`     | ZOH-дискретизация (zero-order hold) через матричную экспоненту. Преобразует непрерывную (A, B) → дискретную (Ad, Bd) с периодом Ts. |
| `design_modal.m`           | Модальный регулятор — **прямое размещение полюсов**. Вы говорите, где должны быть полюса замкнутой системы, MATLAB подбирает K через `place()`. |
| `design_lqr.m`             | ЛКР — оптимальный регулятор по интегральному критерию **J = Σ(x'Qx + u'Ru)**. Решает уравнение Риккати (DARE) через `idare`/`dare`. |
| `design_mpc.m`             | MPC — прогнозирующее управление. Развёртывает динамику на N шагов (lifting), строит QP-матрицы H, f, и явный коэффициент K_first для случая без активных ограничений. |
| `design_observer.m`        | Наблюдатель состояния по Луенбергеру. Восстанавливает полный вектор x по измерениям y = Cx через дуальную задачу pole-placement. |
| `simulate_closed_loop.m`   | Симуляция замкнутой системы x_{k+1} = (Ad − Bd·K)·x_k. Рисует графики состояний и управлений. |
| `export_to_yaml.m`         | Запись всех рассчитанных матриц в `../config.yaml`. Читает существующий файл, заменяет блок `control:`, остальное оставляет нетронутым. |
| `main.m`                   | Оркестратор всего конвейера — вызывает 9 скриптов выше в правильном порядке. |

## Что менять в `samurai_params.m`

| Поле                | Эффект |
|---------------------|--------|
| `Q`                 | Бо́льшие диагональные элементы → точнее держит соответствующее состояние, но реакция резче. |
| `R`                 | Бо́льшие → бережёт управление, реакция плавнее, расход энергии меньше. |
| `N` (горизонт MPC)  | Длиннее горизонт → видит дальше, плавнее огибает «препятствия» в прогнозе, но дороже по CPU. |
| `poles_continuous`  | Прямой выбор полюсов модального регулятора. **Все Re(λ) < 0** для устойчивости. |
| `observer_speedup`  | Во сколько раз наблюдатель быстрее регулятора. **Норма: 5...10.** |
| `tau_v`, `tau_w`    | Постоянные времени моторов. Если шасси другое — измените, иначе модель будет расходиться с реальностью. |

## «Ошибочные» параметры — как намеренно сделать поведение плохим

Это полезно для:
- демонстрации студентам/коллегам, ЧТО происходит при неустойчивости;
- проверки fail-safe (collision_guard) на «убегающем» роботе;
- A/B-сравнения с правильно настроенным регулятором.

| Сделать что          | Эффект                                        |
|----------------------|-----------------------------------------------|
| `poles_continuous = [+1; -1; -1; -1; -1]` | Один полюс в правой полуплоскости → робот «убегает» по экспоненте |
| `Q = -eye(5)`        | Отрицательно определённая Q → DARE не имеет решения, fallback на passthrough |
| `R = 0.01*eye(2)`    | Слишком малый штраф управления → агрессивные команды, насыщение, автоколебания |
| `tau_v = 0.001`      | Модель не соответствует физике → регулятор «думает», что реакция мгновенная, реально она запаздывает на 0.15 с → перерегулирование |
| `Q(1,1) = Q(2,2) = 0`| Регулятор игнорирует позицию → робот «дрейфует», не возвращаясь в (0, 0) |

⚠ **На реальном железе все «ошибочные» режимы опасны.** Тестировать
ТОЛЬКО в симуляторе (`./samurai.sh sim`) или с поднятыми колёсами.

## Зависимости

- MATLAB R2018b+
- Control System Toolbox (`ss`, `dare`, `idare`, `place`, `obsv`, `ctrb`, `expm`)

Если у вас нет Control System Toolbox, можно использовать Octave (большинство
функций совпадают), но `idare` тогда заменится на `dare`. Файлы в комплекте
поддерживают оба варианта (см. условие в `design_lqr.m`).

## Связь с Python-кодом

Цепочка работы:

```
   samurai_params.m              ./samurai.sh robot
        ↓                              ↑
   main.m  →  config.yaml  →  pi_nodes/control/
        ↓                              ↑
   matlab/...  (рассчитанные K)    motor_node @ 20 Hz
```

Каждый шаг строго один раз:
1. **MATLAB main.m** — рассчитывает матрицы (offline, на ноутбуке).
2. **config.yaml** — хранит результат (передаётся на Pi через git).
3. **Python** — читает при старте, применяет в цикле motor_node.

Подробное описание математики — `latex_doc/control_theory/main.pdf`.

## Структура вектора состояния

```
x = [px, py, theta, v, omega]'  ∈ ℝ⁵
u = [u_v, u_omega]'              ∈ ℝ²
```

| Координата | Размерность | Что |
|------------|-------------|-----|
| `px`       | м           | Координата X центра робота в мировой СК |
| `py`       | м           | Координата Y центра робота в мировой СК |
| `theta`    | рад         | Курс (yaw), угол поворота вокруг вертикальной оси |
| `v`        | м/с         | Фактическая линейная скорость (после инерции мотора) |
| `omega`    | рад/с       | Фактическая угловая скорость (после инерции мотора) |
| `u_v`      | м/с         | Желаемая линейная скорость (cmd_vel) |
| `u_omega`  | рад/с       | Желаемая угловая скорость (cmd_vel) |

Линейные размеры: метры. Углы: радианы. Скорости: СИ. Без исключений.
