# Vpered — Arduino Uno firmware

Базовая прошивка для робота **Vpered** (второй робот проекта Samurai).

## Железо

| Компонент | Пины | Примечание |
|-----------|------|------------|
| Мотор L (задний) | PWM1=D5, DIR через 74HC595 | shiftOut DATA=D8, SHCP=D2, STCP=D4, EN=D7 |
| Мотор R (задний) | PWM2=D6 | |
| Клешня (серво) | D11 | |
| Плечо (серво)  | D10 | |
| База (серво)   | D9  | |
| Ультразвук     | TRIG=D12, ECHO=D13 | HC-SR04 |
| Гироскоп       | I2C (A4/A5) | MPU-6050, 0x68 |

WiFi/камеры нет.

## Что делает

1. Калибрует bias гироскопа (робот должен стоять неподвижно ~0.6 сек).
2. Поднимает серво в безопасную позу.
3. `kickStart()` — импульс PWM=255 на оба мотора на 180 мс, плавный спуск до 200.
4. Едет вперёд, держит курс по гироскопу (ПИД по углу Z).
5. Останавливается при расстоянии до препятствия < 10 см.

## Исправление "левые колёса стартуют позже"

Три причины, почему один борт отставал:

1. **Статическое трение выше, чем даёт старт PWM.** Раньше код делал
   `Motor(Forward, 0, 255)` — вместо общего старта разгонял только правые,
   левые продолжали стоять, пока ПИД не накопил ошибку.
   Теперь `kickStart()` даёт **одинаковый** импульс 255 обоим моторам.

2. **PWM проваливался ниже мёртвой зоны** при ПИД-коррекции.
   `MIN_PWM = 120` — строгий нижний порог для обеих сторон.

3. **Механическая разница** (трение подшипников, посадка колёс).
   `LEFT_TRIM = 1.12` — левый получает PWM×1.12.
   Калибруется опытно: если при езде прямо уводит **вправо** → увеличить,
   если **влево** → уменьшить (или поднять `RIGHT_TRIM`).

## Калибровка

Откройте Serial Monitor на 9600 бод. В логе видно:

```
t=1.2s  theta=-0.3  L=204  R=201  dist=120.0
```

- `theta` должна колебаться около 0. Если стабильно уходит в одну сторону —
  подправить `LEFT_TRIM`/`RIGHT_TRIM`.
- `L`/`R` — итоговый PWM на каждый борт.
- `dist` — расстояние до препятствия в см.

## Загрузка

Arduino IDE → Board: Arduino Uno → Port: ваш COM → Upload.

Библиотеки стандартные: `Wire.h`, `Servo.h` (идут с IDE).
