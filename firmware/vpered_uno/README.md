# Vpered — Arduino Uno firmware

Базовая прошивка для робота **Vpered** (второй робот проекта Samurai).

## Железо

| Компонент | Пины | Примечание |
|-----------|------|------------|
| Мотор L (задний) | PWM1=D5, DIR через 74HC595 | shiftOut DATA=D8, SHCP=D2, STCP=D4, EN=D7 |
| Мотор R (задний) | PWM2=D6 | |
| Клешня (серво) | D11 | |
| Плечо (серво)  | D10 | |
| База (серво)   | D9  | |
| Ультразвук     | TRIG=D12, ECHO=D13 | HC-SR04 |
| Гироскоп       | I2C (A4/A5) | MPU-6050, 0x68 |

WiFi/камеры нет.

## Что делает

1. Калибрует bias гироскопа (робот должен стоять неподвижно ~0.9 сек).
2. Поднимает серво в безопасную позу.
3. `kickStart()` — импульс PWM=255 на оба мотора на 150 мс, плавный спуск до 180.
4. Едет вперёд, держит курс по гироскопу (ПИД по углу Z).
5. Останавливается при расстоянии до препятствия < 10 см.

## Если едет по кругу — диагностика

Кружить может по двум причинам: **знак ПИД перепутан** или **физическая
асимметрия моторов**. Различить просто:

### Шаг 1. Включить разомкнутый цикл

В `vpered_uno.ino` раскомментируй строку:

```cpp
#define OPEN_LOOP
```

Залей. ПИД полностью отключён, оба мотора получают равный PWM.

- **Едет прямо или почти прямо** → проблема была в ПИД. Закомментируй
  `OPEN_LOOP` обратно и в строке `const int GYRO_SIGN = +1;` поменяй
  знак на `-1`. Залей. Ось Z гироскопа на твоём шасси перевёрнута —
  `GYRO_SIGN` это компенсирует.
- **Крутится в ту же сторону** → асимметрия моторов. См. шаг 2.

### Шаг 2. Подобрать LEFT_TRIM (если сторона перекошена)

Оставь `OPEN_LOOP` включённым. В `vpered_uno.ino`:

```cpp
const float LEFT_TRIM  = 1.10f;   // подбирать
const float RIGHT_TRIM = 1.00f;
```

- Робот уводит **вправо** → левый слабее → увеличить `LEFT_TRIM` (1.05, 1.10, 1.15…).
- Робот уводит **влево** → правый слабее → увеличить `RIGHT_TRIM`.

Когда в OPEN_LOOP едет прямо — закомментируй `OPEN_LOOP`, оставь подобранный
trim, и ПИД будет уже на этой базе.

### Шаг 3. Если ПИД нестабилен (виляет)

Уменьши коэффициенты:

```cpp
float Kp = 0.5f;
float Kd = 0.15f;
```

## Калибровка

Откройте Serial Monitor на 9600 бод. В логе видно:

```
t=1.2s  theta=-0.3  omega=2.1  L=178  R=182  dist=120.0
```

- `theta` должна колебаться около 0. Стабильно растёт в одну сторону →
  знак гироскопа (`GYRO_SIGN`) или trim моторов.
- `omega` — текущая угловая скорость (deg/s). Должна быть около 0 при
  движении прямо.
- `L`/`R` — итоговый PWM на каждый борт.
- `dist` — расстояние до препятствия в см.

## Загрузка

Arduino IDE → Board: Arduino Uno → Port: ваш COM → Upload.

Библиотеки стандартные: `Wire.h`, `Servo.h` (идут с IDE).

## Известные warning'и

- `requestFrom` — устранён явным кастом аргументов в `(uint8_t)`.
