# Vpered — калибровка руки и клешни

Отдельный скетч для подбора углов трёх серв (BASE D9, ARM D10, CLAW D11)
и проверки последовательности захвата объекта.

## Зачем отдельный скетч

Основная прошивка `vpered_uno/` отвечает за езду (моторы + гироскоп + ультразвук).
Калибровать там руку неудобно — пришлось бы триггерить её в цикле движения.
Здесь робот **не едет**, только работает с сервами.

После калибровки — перенеси подобранные константы в основную прошивку.

## Что делает

- Стартует с руки в безопасной парк-позе (ARM=90°, BASE=90°, CLAW=135°).
- Ждёт команды из Serial Monitor (9600 бод).
- По команде двигает серво плавно (шаг 1° с 8 мс задержкой — без рывков).
- Команда `g` запускает полную последовательность:
  `open claw → arm forward → pause → close claw → arm up`.

## Команды Serial

### Управление углами
| Клавиша | Что делает |
|---------|------------|
| `b` / `B` | BASE −step / +step |
| `a` / `A` | ARM  −step / +step |
| `c` / `C` | CLAW −step / +step |
| `1` / `5` / `0` | размер шага: 1° / 5° / 10° (default 2°) |

### Пресеты и последовательность
| Клавиша | Что делает |
|---------|------------|
| `o` | открыть клешню (на `CLAW_OPEN`) |
| `x` | закрыть клешню (на `CLAW_CLOSED`) |
| `~` | **swap** `CLAW_OPEN` ↔ `CLAW_CLOSED` (если `o` и `x` работают наоборот) |
| `f` | рука вперёд (поза захвата) |
| `p` | рука в парк |
| `g` | **полная последовательность захвата** |
| `r` | reset в парк |

### Сохранение текущего положения как пресет (двухсимвольная команда)
| Клавиши | Что делает |
|---------|------------|
| `s` `o` | текущий CLAW → `CLAW_OPEN` |
| `s` `x` | текущий CLAW → `CLAW_CLOSED` |
| `s` `f` | текущие BASE+ARM → FORWARD |
| `s` `p` | текущие BASE+ARM+CLAW → PARK |

### Экспорт
| Клавиша | Что делает |
|---------|------------|
| `e` | печатает готовый copy-paste блок констант для основной прошивки |
| `?` | показать текущие углы и пресеты |
| `h` | справка |

## Как подбирать углы

Все пресеты можно подобрать **из Serial без перепрошивки**.

1. **Постановка**. Робот с объектом впереди, серво запитаны, Serial на 9600.
2. **Проверь полярность клешни**. Нажми `o`:
   - Если клешня **открылась** — ок.
   - Если **закрылась** — нажми `~` (swap). Теперь `o` открывает, `x` закрывает.
3. **Подбери позу «рука вперёд»**. Двигай `b`/`B` (база — влево/вправо) и
   `a`/`A` (плечо — выше/ниже), пока клешня не окажется точно вокруг объекта.
   Сохрани: `s` затем `f` → BASE+ARM запомнились как FORWARD.
4. **Подбери открытую клешню**. `c`/`C` пока пальцы не пройдут по бокам
   объекта с небольшим зазором. Сохрани: `s` затем `o` → это `CLAW_OPEN`.
5. **Подбери закрытую клешню**. `c`/`C` пока объект не зажимается уверенно,
   но **без перегрузки** (серво не должна жужжать/нагреваться). `s` затем `x`.
6. **При желании — парк-позу**. Подними руку в безопасное положение,
   `s` затем `p`.
7. **Проверь всё**: `r` (сброс в парк), затем `g` — выполнит полную
   последовательность с новыми пресетами.
8. **Экспортируй**: нажми `e` — в Serial выведется готовый блок:
   ```cpp
   const int BASE_FORWARD = 90;
   const int ARM_FORWARD  = 38;
   const int CLAW_OPEN    = 65;
   const int CLAW_CLOSED  = 155;
   ...
   ```
   Скопируй в `vpered_uno.ino`.

> Пресеты сбрасываются при перезапуске Arduino (держатся в RAM).
> Поэтому обязательно нажми `e` и сохрани значения в основной код.

## Перенос в основную прошивку

В `firmware/vpered_uno/vpered_uno.ino` уже есть `armSafePose()`. Добавь туда
константы `CLAW_OPEN/CLOSED`, `ARM_FORWARD` и функции `openClaw()` /
`closeClaw()` / `grabSequence()` — можно скопировать блок целиком из этого
скетча, он изолирован от моторов и гироскопа.

## Серво греется и жужжит

Это **самая частая проблема** с хобби-сервами (SG90/MG90/MG995 и т.п.).
Причины и решения:

### 1. Постоянное удержание момента

Даже когда серво приехало, оно продолжает «зажимать» позицию — мотор под током,
ШИМ идёт непрерывно. На нагрузке (закрытая клешня, поднятая рука) греется
за секунды.

**Решение в коде (уже сделано):**

- `autoDetach = true` по умолчанию. Если серво не двигалось
  `DETACH_IDLE_MS = 600 мс` — ШИМ отключается. Серво молчит,
  механика держит за счёт трения в редукторе.
- Команда `d` — detach немедленно (если серво жужжит прямо сейчас).
- Команда `D` — toggle авто-detach.

> ⚠️ Если ARM тяжёлое — при detach плечо **упадёт** под своим весом.
> Тогда выключи auto-detach (`D`) и/или подбирай пресеты осторожно.
> На BASE и CLAW detach почти всегда безопасен.

### 2. Зажато «в упор»

`CLAW_CLOSED = 160` может быть за механическим пределом клешни —
пальцы упираются друг в друга, серво не может дойти до цели и тянет
максимальный момент. **Оставь 5–15° запаса:**

```cpp
int CLAW_CLOSED = 150;   // не 160
```

Подбирай углом `c`/`C` пока объект зажимается уверенно, но серво
не жужжит. Далее — `sx` чтобы сохранить.

### 3. Недостаток питания

Серво в движении под нагрузкой берёт **1–2 А** (SG90 ≈ 0.7 А, MG995 ≈ 1.5 А).
Arduino 5V через USB даёт максимум **500 мА** — просадка напряжения,
жужжание, перезагрузки.

**Железное решение:**
- Отдельный источник 5–6 В с током ≥ 2 А на все серво (BEC, LiPo + UBEC,
  4×AA NiMH).
- **Общая земля** Arduino и сервы обязательна, иначе ШИМ не проходит.
- Питание Arduino оставить через USB или VIN (7–12 В).

Схема:
```
       +5–6V ──┬── CLAW red
               ├── ARM  red
               └── BASE red

       GND ────┬── CLAW black
               ├── ARM  black
               ├── BASE black
               └── Arduino GND   (ОБЩАЯ!)

       D11 ──── CLAW signal (orange/yellow)
       D10 ──── ARM  signal
       D9  ──── BASE signal
```

### 4. Ещё причины

- **Рука дёргается рывком** — `Servo.write()` без плавной подачи.
  Используй `smoothWriteServo()` (уже используется).
- **Угол за 0–180°** — серво упирается в механический стоп. `constrain(tgt, 0, 180)`
  в `smoothWriteServo` уже это предотвращает, но если механика не выдерживает
  углов 5° / 175° — сузь диапазон вручную в коде.

## Типичные проблемы

- **Рука не достаёт до объекта** — уменьшай `ARM_FORWARD` (ниже число = ниже
  плечо). Если механический предел не хватает — подвинь робота ближе.
- **`o` и `x` перепутаны** — нажми `~` (swap полярности).
- **Пресеты сбросились после reset Arduino** — нормально, они в RAM.
  После калибровки нажми `e` и скопируй в основной код.
