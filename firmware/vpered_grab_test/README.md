# Vpered — калибровка руки и клешни

Отдельный скетч для подбора углов трёх серв (BASE D9, ARM D10, CLAW D11)
и проверки последовательности захвата объекта.

## Зачем отдельный скетч

Основная прошивка `vpered_uno/` отвечает за езду (моторы + гироскоп + ультразвук).
Калибровать там руку неудобно — пришлось бы триггерить её в цикле движения.
Здесь робот **не едет**, только работает с сервами.

После калибровки — перенеси подобранные константы в основную прошивку.

## Что делает

- Стартует с руки в безопасной парк-позе (ARM=90°, BASE=90°, CLAW=135°).
- Ждёт команды из Serial Monitor (9600 бод).
- По команде двигает серво плавно (шаг 1° с 8 мс задержкой — без рывков).
- Команда `g` запускает полную последовательность:
  `open claw → arm forward → pause → close claw → arm up`.

## Команды Serial

| Клавиша | Что делает |
|---------|------------|
| `b` / `B` | BASE −step / +step |
| `a` / `A` | ARM  −step / +step |
| `c` / `C` | CLAW −step / +step |
| `1` / `5` / `0` | размер шага: 1° / 5° / 10° (default 2°) |
| `o` | открыть клешню на `CLAW_OPEN` |
| `x` | закрыть на `CLAW_CLOSED` |
| `f` | рука вперёд (поза захвата) |
| `p` | рука в парк |
| `g` | **полная последовательность захвата** |
| `r` | reset в парк |
| `?` | показать текущие углы и пресеты |
| `h` | справка |

## Как подбирать углы

1. **Постановка**. Робот с объектом на нужном расстоянии впереди. Электропитание
   серв включено. Открой Serial Monitor на 9600.
2. **Нажми `f`** — рука идёт в `ARM_FORWARD`. Клешня должна оказаться вокруг
   объекта. Если не совпадает — двигай:
   - `a`/`A` — подъём/опускание (если клешня выше/ниже объекта)
   - `b`/`B` — поворот базы (если клешня сбоку)
3. **Нажми `o`** — клешня открывается. Подбирай `c`/`C` пока пальцы не пройдут
   по бокам объекта со свободным зазором. Запомни угол (в `?` увидишь `CLAW =`).
4. **Нажми `x`** — закрывается. Подбирай пока объект не зажимается уверенно,
   но **без натуги** (серво начнёт жужжать и греться при перегрузке).
5. Откорректируй в коде константы и перезалей:
   ```cpp
   int BASE_FORWARD = 90;
   int ARM_FORWARD  = 40;
   int CLAW_OPEN    = 160;
   int CLAW_CLOSED  = 70;
   ```
6. **Нажми `g`** — выполнить всю последовательность целиком. Если нормально
   хватает и поднимает — калибровка готова.

## Перенос в основную прошивку

В `firmware/vpered_uno/vpered_uno.ino` уже есть `armSafePose()`. Добавь туда
константы `CLAW_OPEN/CLOSED`, `ARM_FORWARD` и функции `openClaw()` /
`closeClaw()` / `grabSequence()` — можно скопировать блок целиком из этого
скетча, он изолирован от моторов и гироскопа.

## Типичные проблемы

- **Серва жужжит и не двигается** — угол за пределами физического диапазона
  (<0° или >180°). Проверь `constrain` или скорректируй пресет.
- **Рука дёргается рывком** — значит где-то пишется `servo.write()` без
  плавной подачи. Используй `smoothWriteServo()` из этого скетча.
- **Серва перегревается** — неправильный `CLAW_CLOSED` (слишком сжато), серво
  постоянно держит момент. Ослабь угол на 5–10°.
- **Рука не достаёт до объекта** — уменьшай `ARM_FORWARD` (ниже число = ниже
  плечо). Если механический предел не хватает — надо подвинуть робот ближе.
